# Camel Paper Catálogo

Primeira versão visual do catálogo interno da Camel Paper.

## Rodar no Mac

```bash
npm install
npm run dev
```

Depois abra http://localhost:3000

## Nesta versão
- Identidade visual Camel Paper
- Lista inicial de produtos reais do catálogo fornecido
- Busca por nome, SKU e código de barras
- Filtro por categoria
- Estrutura responsiva

Próxima etapa: Supabase, login, cadastro e edição real de produtos.
